```
1. **基准测试**
   - 禁用能力感知，测量 100 次对话的平均响应时间

2. **Token 增量测试**
   - 记录禁用时的平均 token 数

   - 使用 `time.perf_counter()` 测量 `CapabilityDescriptionBuilder.format_as_system_prompt_block()` 耗时
   - 测试不同规模（1/5/10 个技能，1/5/10 个知识库）

**输出**:
- 性能测试报告（表格形式）
- 瓶颈分析
- 优化建议（如需要）

**接受标准**:
- 响应时间增加 < 10%
- Token 增加 < 500 tokens
- 构建耗时 < 50ms
```
