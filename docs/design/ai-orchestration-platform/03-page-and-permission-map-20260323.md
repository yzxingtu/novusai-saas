# AI 编排与工作流平台页面与权限草案（2026-03-23）

## 一、文档目标

本文档用于定义：

- 管理端应该有哪些页面
- 企业端应该有哪些页面
- 哪些页面负责“治理与分发”
- 哪些页面负责“使用与运营”
- 哪些能力只允许管理端，哪些能力允许企业端

本文档的核心原则是：

> 平台方负责生产、授权、治理；企业方负责使用、配置、轻编排和审批实例管理。

---

## 二、平台角色边界

### 2.1 管理端

管理端负责：

- 插件市场治理
- 行业解决方案上架
- 授权和计费
- 平台级模板制作
- 代码型工作流制作
- 企业定制交付
- 风险基线和审批基线
- 全局运行监控与安全干预

管理端不负责：

- 代替企业做日常运营
- 代替企业审批本企业业务实例
- 日常修改企业自有简单工作流

### 2.2 企业端

企业端负责：

- 启用已授权方案
- 上传业务知识和素材
- 配置企业 Agent 和 Prompt 参数
- 复制平台模板并做轻量定制
- 创建简单工作流
- 管理本企业审批实例
- 管理草稿、运行结果和复盘

企业端不负责：

- 安装插件
- 编写代码型工作流
- 新增连接器或执行器
- 修改平台级能力和风险基线

---

## 三、管理端页面清单

### 3.1 插件市场

建议页面：

- 插件市场首页
- 插件详情页
- 插件安装 / 升级 / 禁用管理
- 插件版本记录

页面职责：

- 管理所有插件，包括能力插件与解决方案插件
- 展示插件分类、版本、授权状态、运行状态

权限建议：

- `plugin:market:list`
- `plugin:market:detail`
- `plugin:install`
- `plugin:upgrade`
- `plugin:disable`

### 3.2 行业解决方案管理

建议页面：

- 方案包列表
- 方案包详情
- 方案包授权页面
- 方案包定价与交付配置

页面职责：

- 展示所有 `solution_plugin`
- 维护行业分类、上架状态、售卖信息
- 绑定默认模板、Agent、Skill、审批策略

### 3.3 平台工作流模板中心

建议页面：

- 工作流模板列表
- 模板编辑器
- 模板版本页
- 模板发布页

页面职责：

- 管理平台级模板
- 创建托管型可视化工作流
- 创建代码型工作流的分发入口

### 3.4 代码型工作流交付中心

建议页面：

- 定制交付任务列表
- 企业定制工作流详情
- 交付版本记录
- 指定企业授权页面

页面职责：

- 管理平台为企业制作的专属流程
- 记录交付状态和升级记录

### 3.5 授权与计费中心

建议页面：

- 套餐管理
- 企业授权管理
- 方案包授权管理
- 定制交付授权管理
- 用量与账单管理

### 3.6 风险与审批治理中心

建议页面：

- 风险等级配置
- 审批策略配置
- 平台默认审批基线
- 高风险动作黑白名单

### 3.7 运行监控中心

建议页面：

- 全局 Run 列表
- 全局失败任务列表
- 高风险运行列表
- 成本分析
- 审计回放页

页面职责：

- 全局监控与应急处理
- 禁用异常模板、异常插件、异常工作流

---

## 四、企业端页面清单

### 4.1 已授权方案首页

建议页面：

- 解决方案首页
- 我可用的行业方案列表
- 方案详情与启用配置

页面职责：

- 展示企业已获得授权的方案包
- 启用或停用企业侧可见能力

### 4.2 企业知识与资产中心

建议页面：

- 品牌与业务配置
- 知识库管理
- 素材库
- 样例库
- SOP 配置页

页面职责：

- 企业上传自己的业务知识
- 给行业方案提供上下文和资产

### 4.3 企业工作流中心

建议页面：

- 我的工作流列表
- 从平台模板创建
- 简单工作流编辑器
- 工作流版本与启停

页面职责：

- 企业创建和管理简单工作流
- 复制平台模板为企业工作流副本

### 4.4 企业 Agent 中心

建议页面：

- 企业 Agent 列表
- Agent 配置页
- Agent 绑定的已授权能力列表

页面职责：

- 管理企业自己的 Agent 配置
- 不允许越权绑定未授权能力

### 4.5 审批中心

建议页面：

- 待审批列表
- 审批详情页
- 审批记录页

页面职责：

- 企业管理员处理本企业审批任务
- 管理端不代替企业审批业务实例

### 4.6 运行与复盘中心

建议页面：

- 运行历史
- 草稿中心
- 执行结果详情
- 复盘与优化建议页

页面职责：

- 企业查看自己流程的执行结果
- 管理草稿、报告、复盘结论

---

## 五、页面权限边界

### 5.1 管理端独占能力

只允许管理端：

- 安装 / 升级 / 禁用插件
- 上架行业方案插件
- 创建代码型工作流
- 创建平台级模板
- 发放企业授权
- 配置平台级审批基线
- 执行全局安全禁用

### 5.2 企业端独占能力

只允许企业端：

- 管理企业知识和素材
- 创建企业简单工作流
- 管理企业工作流副本
- 管理企业审批实例
- 查看企业运行记录与草稿

### 5.3 共享但受边界约束的能力

管理端和企业端都可能看到，但权限完全不同：

- 方案详情
- 工作流详情
- Agent 详情
- 审批记录
- 运行监控

管理端看的是治理和全局视角，企业端看的是自己企业的使用与运营视角。

---

## 六、企业可创建能力矩阵

### 6.1 企业允许创建

- 企业简单工作流
- 企业工作流副本
- 企业 Agent 参数配置
- 企业审批规则中的局部配置
- 企业知识、素材、业务规则

### 6.2 企业不允许创建

- 代码型工作流
- 新插件
- 新连接器
- 新执行器
- 新系统级 Skill
- 平台级审批策略基线

### 6.3 企业允许复制但受控

企业端可对以下对象做“复制为企业版”：

- 平台模板
- 平台行业方案中的可编辑模板
- 平台提供的 Agent 预设

但不允许：

- 修改平台原件
- 修改未授权字段
- 去掉强制审批节点

---

## 七、最小行业样板页面建议：爆款短视频增长方案包

### 7.1 管理端页面

建议增加：

- `方案包详情：爆款短视频`
- `模板管理：热点选题 / 脚本生成 / 内容审核 / 复盘优化`
- `企业授权页：哪些企业已购买`
- `定制交付页：是否为某企业做专属模板`

### 7.2 企业端页面

建议增加：

- `爆款短视频工作台`
- `热点池`
- `脚本草稿库`
- `内容审核列表`
- `复盘中心`

### 7.3 第一阶段边界

企业端第一阶段只做：

- 选题
- 脚本草稿
- 标题与封面文案
- 审核
- 草稿归档

不做：

- 外部平台自动发布
- 多平台一键投放
- 账号自动运维

## 八、推荐的页面建设顺序

### Phase 1：管理端治理页

- 插件市场
- 方案包管理
- 企业授权管理
- 平台模板中心

### Phase 2：企业端使用页

- 已授权方案页
- 企业知识与素材页
- 企业工作流中心
- 审批中心

### Phase 3：运行与审计页

- 管理端全局监控
- 企业端运行与复盘
- 草稿与产物中心

### Phase 4：行业样板页

- 爆款短视频工作台
- 热点池
- 脚本草稿库
- 审核与复盘页

---

## 九、关键结论

1. 管理端页面重点是治理、分发、授权、售卖、交付。
2. 企业端页面重点是使用、注入知识、轻编排、审批实例管理、复盘。
3. 企业端不能变成“开发者后台”，而应是“业务配置与运营后台”。
4. 平台必须通过页面结构明确体现“平台资源”和“企业资源”的边界。
5. 最小行业样板的页面设计必须服务于平台验证，而不是一开始追求行业功能大而全。
