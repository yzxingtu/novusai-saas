# 爆款短视频增长方案包详细样板（2026-03-23）

## 一、文档目标

本文档用“爆款短视频增长方案包”作为最小行业样板，验证平台内核是否能支撑：

- 行业方案插件
- 模板分发
- 企业配置注入
- AI 编排与审批
- 草稿归档与复盘

本样板的目标不是把短视频行业功能一次做全，而是验证平台最关键的三件事：

1. 行业方案如何以插件形式交付。
2. 企业如何在不写代码的前提下使用方案。
3. AI 编排、审批、草稿和复盘如何形成闭环。

---

## 二、样板定位

### 2.1 方案名称

- 中文名：`爆款短视频增长方案包`
- 插件名建议：`short-video-growth`

### 2.2 面向对象

适用于以下类型团队：

- 品牌内容团队
- 电商内容运营团队
- 达人工作室
- 代运营团队
- 需要用 AI 做选题、脚本和复盘的企业

### 2.3 第一阶段边界

第一阶段只做到：

- 趋势发现
- 选题生成
- 脚本生成
- 标题与封面文案生成
- 内容审核
- 草稿归档
- 复盘建议

第一阶段明确不做：

- 直接发布到抖音
- 直接发布到快手
- 多平台自动投放
- 自动评论互动
- 账号矩阵自动运营

这是一个刻意收敛后的样板，用于验证平台，不是完整行业产品终态。

---

## 三、该样板为什么适合做第一批

这个样板适合作为平台首个行业包，原因有三：

### 3.1 编排感足够强

它天然包含：

- 联网分析
- 竞品拆解
- 内容生成
- 品牌审核
- 草稿归档
- 数据复盘

因此可以很好验证 `deterministic`、`hybrid`、`agentic` 三种模式。

### 3.2 风险可控

第一阶段只做到草稿，不直接对外发布，因此：

- 平台仍然需要审批和审核
- 但不会马上进入最高风险的“外部写操作”

### 3.3 企业价值容易体现

企业在这个样板中的核心价值不是造工具，而是提供：

- 品牌调性
- 账号定位
- 产品信息
- 素材和历史数据
- 审核规则

这与平台总原则完全一致。

## 六、内置工作流模板设计

### 6.1 趋势扫描工作流

建议编码：`short_video_trend_scan`

### 目标

识别近期平台热点、竞品高频主题和可借势方向。

### 建议流程

```text
输入赛道与账号定位
-> 联网检索热点
-> 抽取竞品高表现内容
-> 归纳主题模式
-> 生成趋势分析报告
-> 入库趋势池
```

### 模式建议

- `hybrid`

### 输出

- 趋势报告
- 主题榜单
- 竞品参考摘要

### 风险等级

- 默认 `R0` 或 `R1`

### 审批要求

- 无正式审批
- 记录检索来源和抓取时间

### 6.2 选题池生成工作流

建议编码：`short_video_topic_pool`

### 目标

根据趋势、企业品牌与产品信息，生成可执行的选题池。

### 建议流程

```text
读取趋势池
-> 读取品牌和产品资料
-> 生成候选选题
-> 计算匹配度与风险提示
-> 人工筛选
-> 入库选题池
```

### 模式建议

- `hybrid`

### 输出

- 候选选题列表
- 选题优先级
- 风险提示

### 风险等级

- 默认 `R1`

### 审批要求

- 由运营人工筛选后入库
- 可采用请求人确认，不一定需要正式审批

### 6.3 脚本草稿生成工作流

建议编码：`short_video_script_draft`

### 目标

基于选题生成多版本脚本草稿、标题和封面文案。

### 建议流程

```text
选择选题
-> 读取品牌资料和历史高表现样本
-> 生成 3 套结构
-> 生成脚本草稿
-> 生成标题和封面文案
-> 形成草稿包
-> 保存草稿库
```

### 模式建议

- `hybrid`
- 局部可升级为 `agentic`

### 输出

- 脚本草稿
- 标题备选
- 封面文案
- 推荐标签

### 风险等级

- 默认 `R1`

### 审批要求

- 保存为草稿时可不走正式审批
- 如要覆盖已有高优草稿或批量替换，提升到 `R2`

### 6.4 内容审核工作流

建议编码：`short_video_content_review`

### 目标

在进入“可交付草稿”前，对内容做品牌、规则和表达审核。

### 建议流程

```text
读取草稿包
-> 品牌调性检查
-> 敏感词与违规表达检查
-> 事实与夸大风险检查
-> 给出修改建议
-> 人工审核
-> 归档可交付草稿
```

### 模式建议

- `deterministic` 或 `hybrid`

### 输出

- 审核结论
- 修改建议
- 风险标注
- 最终草稿版本

### 风险等级

- 默认 `R2`

### 审批要求

- 建议单人正式审批
- 审批角色通常为品牌负责人或内容负责人

### 6.5 周复盘工作流

建议编码：`short_video_weekly_retrospective`

### 目标

基于历史表现和最近内容结果，输出下一周优化建议。

### 建议流程

```text
读取最近表现数据
-> 找高表现样本和低表现样本
-> 归纳差异
-> 输出下周建议
-> 形成复盘报告
```

### 模式建议

- `hybrid`

### 输出

- 复盘报告
- 下周选题建议
- 风格调整建议
- 风险提醒

### 风险等级

- 默认 `R0`

### 审批要求

- 无正式审批

## 七、Agent 预设建议

建议内置以下 Agent 预设：

| Agent 编码 | 角色 | 主要职责 |
|---|---|---|
| `short_video_trend_analyst` | 趋势分析师 | 热点抓取、竞品拆解、主题归纳 |
| `short_video_content_strategist` | 内容策划师 | 选题设计、结构建议、内容方向判断 |
| `short_video_script_writer` | 脚本编导 | 口播稿、镜头结构、标题与封面文案 |
| `short_video_review_assistant` | 审核助手 | 品牌、规则、表达和风险检查 |
| `short_video_ops_analyst` | 复盘分析师 | 表现归因、优化建议、下周规划 |

### 7.1 与能力授权的关系

这些 Agent 只是预设，不应直接绕过平台的授权体系。

运行时仍然必须：

- 通过 `AgentSkillGrant` 挂接允许的 Skill
- 受企业授权和方案授权约束

## 八、审批与风险建议

### 8.1 第一阶段风险矩阵

| 动作 | 默认风险 | 默认闸门 |
|---|---|---|
| 趋势扫描 | `R0` | 直接执行 |
| 选题生成 | `R1` | 直接执行或请求人确认 |
| 生成脚本草稿 | `R1` | 直接执行 |
| 覆盖已有草稿 | `R2` | 单人审批或确认 |
| 最终草稿归档为可交付版本 | `R2` | 单人审批 |
| 批量覆盖草稿库 | `R3` | 双人审批 |

### 8.2 为什么第一阶段不碰外部发布

一旦进入对外发布，风险会立刻上升：

- 变成外部写操作
- 可能影响品牌
- 可能触发平台规则违规
- 需要更强证据链

所以第一阶段应把闭环控制在“草稿完成”为止。

### 8.3 第二阶段扩展条件

未来如要加入“直接发布”，建议满足：

1. 独立发布能力插件
2. 更严格审批策略
3. 发布前预览包
4. 发布后回执记录
5. 可撤回或补救策略

## 十三、关键结论

1. “爆款短视频增长方案包”是一个很适合做第一批行业样板的场景，因为它既有明显的 AI 编排价值，又能把风险控制在草稿阶段。
2. 第一阶段应只做到“趋势分析 -> 选题 -> 脚本 -> 审核 -> 草稿 -> 复盘”闭环，不直接进入外部平台自动发布。
3. 企业在这个样板中的核心价值是提供品牌、产品、规则、素材和历史数据，而不是自己开发底层工具。
4. 该样板已经足够覆盖插件分发、模板管理、企业配置、审批、草稿和复盘等平台关键内核。
5. 如果这个样板能跑通，后续扩展到电商分析、销售运营、客服 SOP、内容投放等行业包会更自然。
