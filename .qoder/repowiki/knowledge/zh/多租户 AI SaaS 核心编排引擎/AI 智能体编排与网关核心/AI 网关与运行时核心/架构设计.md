- **统一网关门面**：`AIGateway` 作为核心入口，通过 `AdapterRegistry` 屏蔽不同 AI 供应商的 API 差异，支持聊天、嵌入和图像生成。
- **分层治理组件**：采用组合模式集成 `QuotaManager`（数据库级租户配额）、`AgentQuotaManager`（Redis 级智能体配额）、`RateLimiter`（滑动窗口限流）和 `RetryService`（指数退避与 Key 轮换）。
- **高可用保障**：`FailoverService` 基于 Redis 健康状态实现模型链式故障转移；`SSEStreamingResponse` 处理流式响应并管理 Token 计量回调。
- **事件驱动解耦**：内置 `EventBus` 实现进程内异步发布/订阅，支持优先级调度与错误隔离，覆盖智能体生命周期、工具调用及执行引擎事件。
- **提示词契约化**：`prompt_contracts` 子包通过 Jinja2 模板引擎管理面向模型的提示词片段，实现业务逻辑与 Prompt 文本的解耦。
