- **模块化架构**：采用扁平化文件结构，通过 `_` 前缀区分内部辅助模块（如 `_agent_helpers.py`, `_kb_helpers.py`）与公开接口定义（`recycle_bin_registry.py`, `rich_text_ai_schemas.py`）。
- **核心组件**：
  - `recycle_bin_registry.py`：作为回收站功能的中央注册表，通过 `RECYCLABLE_MODULES` 字典动态映射模型、服务与国际化配置，支持多租户与管理端的统一删除恢复逻辑。
  - `rich_text_ai_schemas.py`：定义富文本 AI 操作的 Pydantic 请求模型，确保两端输入契约一致。
  - `_rich_text_ai_operations.py`：封装基于 SSE 的流式响应标准化逻辑，处理 AgentChat 服务的流式输出转换与错误追踪。
- **依赖方向**：所有辅助函数均依赖于底层 Service 层与 Model 层，不直接暴露路由，而是被 `admin` 和 `tenant` 目录下的控制器导入调用，实现业务逻辑复用。
