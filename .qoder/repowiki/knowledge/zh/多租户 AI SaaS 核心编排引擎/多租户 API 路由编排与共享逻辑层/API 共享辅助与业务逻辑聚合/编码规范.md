- 以 `_` 开头的文件名用于存放内部辅助函数，避免被外部直接导入，体现模块内部的封装边界。
- 在序列化 ORM 对象时，普遍使用 `getattr(obj, field, default)` 或自定义的 `_get_package_value` 工具函数，以兼容字典与 ORM 实例并安全处理缺失属性。
- 涉及多端（Admin/Tenant）共用的列表项构建逻辑（如 `_build_agent_item`, `build_assignment_item`）均提取为独立函数，接收基础对象后返回标准化字典。
- 在处理敏感配置（如 `valves_config`）时，遵循“读取时脱敏、写入时合并”的模式，通过 `_toolkit_helpers.py` 中的 `mask_secret_values` 统一处理密钥字段的掩码显示。
