- **入口与聚合**：`__init__.py` 定义 `public_router` (FastAPI `APIRouter`)，通过 `include_router` 统一挂载 `health`, `tenant`, `captcha`, `platform`, `attachments` 子模块。
- **权限控制**：所有端点均使用 `@public` 装饰器（来自 `app.rbac.decorators`），标记为无需身份验证或权限检查的公开资源。
- **响应规范**：业务接口统一使用 `app.core.response.success` 封装标准 JSON 结构；健康检查等特殊接口直接使用 `JSONResponse` 以适配负载均衡探活需求。
- **依赖注入**：通过 `DbSession` 注入数据库会话，利用 `get_tenant_context` 中间件上下文实现基于域名的多租户自动识别与配置隔离。
- **服务分层**：控制器层保持轻量，核心逻辑委托给 `ConfigService`、`captcha_service`、`AttachmentDownloadService` 等服务层组件处理。
