- **路由聚合架构**：以 `__init__.py` 为入口，通过 `APIRouter.include_router` 聚合 40+ 个子模块路由，形成统一的 `/admin` 命名空间。
- **控制器基类体系**：所有业务控制器继承自 `GlobalController`（定义于 `app/core/base_controller.py`），采用单例模式注册路由，确保全局上下文无租户隔离。
- **声明式权限模型**：深度集成 `@permission_resource` 与 `@action_*` 装饰器（定义于 `app/rbac/decorators.py`），在类导入时自动向 `PermissionRegistry` 注册菜单与操作权限，实现权限元数据与代码逻辑的同步。
- **模块化子域划分**：内部按功能域拆分为独立文件，如 `tenants.py`（多租户管理）、`ai_*.py`（AI 供应商/模型/网关/智能体）、`plugins.py`（插件全生命周期）及 `system_logs.py` 等，各子模块通过 `Admin*Service` 与底层业务逻辑解耦。
- **通用能力复用**：通过 `register_admin_recycle_bin_routes` 等工具函数为多个资源模块（如 Agents, Tenants, AI Providers）统一注入回收站 RESTful 接口，减少重复代码。
