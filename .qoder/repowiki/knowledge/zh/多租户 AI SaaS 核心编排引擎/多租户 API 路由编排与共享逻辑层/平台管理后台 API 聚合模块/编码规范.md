- 控制器类必须使用 `@permission_resource` 装饰器并继承 `GlobalController`，且在 `__init__.py` 中显式导出控制器类以触发权限注册。
- 路由定义统一采用在 `_register_routes` 方法内嵌套 FastAPI 路由函数的模式，并通过 `self.router` 实例进行注册。
- 接口响应统一使用 `app.core.response` 提供的 `success`, `created`, `paginated` 等标准化包装函数，确保返回结构一致。
- 涉及敏感操作或状态变更的接口（如删除、禁用）优先采用软删除或状态位切换，并配合 `ActiveAdmin` 依赖注入记录操作人。
