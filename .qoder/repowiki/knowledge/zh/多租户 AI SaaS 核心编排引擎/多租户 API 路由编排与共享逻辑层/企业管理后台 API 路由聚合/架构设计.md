- 入口与聚合：`__init__.py` 创建 `tenant_router` (FastAPI `APIRouter`)，统一 `include_router` 导入的子模块路由（如 `auth`, `agents`, `knowledge_bases`），并导出控制器类以触发权限装饰器注册。
- 控制器模式：采用基于类的控制器（如 `TenantAgentController`），继承自 `app.core.base_controller.TenantController`；通过 `_register_routes` 在实例化时动态注册路由，并利用单例模式确保路由只注册一次。
- 权限自动化：使用 `@permission_resource` 装饰控制器类定义资源边界，配合 `@action_read/create/update/delete` 装饰具体端点；`BaseController.get_router` 在懒加载时调用 `register_action_permissions` 自动扫描并注册权限元数据到全局 Registry。
- 业务隔离：控制器方法依赖注入 `ActiveTenantAdmin` 和 `DbSession`，服务层（如 `AgentService`）显式传入 `tenant_id` 以实现数据行级隔离；部分模块（如 `agents.py`）包含辅助函数（如 `_ensure_tenant_owned_agent`）强制执行所有权校验。
- 模块化拆分：大型资源（如智能体）通过内部子路由文件（`_agent_batch.py`, `_agent_skills.py` 等）进一步拆分逻辑，并在控制器的 `_register_routes` 末尾通过 `router.include_router` 挂载。
