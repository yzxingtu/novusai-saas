- 控制器类必须使用 `@permission_resource` 装饰器声明资源标识、作用域及菜单配置，以自动注册菜单权限并作为操作权限的父节点。
- 所有需要权限控制的端点方法必须使用 `@action_read`、`@action_create` 等快捷装饰器，装饰器参数通常传入 i18n key（如 `action.agent.list`）以自动推导权限码。
- 涉及数据变更（增删改）的接口在执行前通常调用辅助函数（如 `_ensure_tenant_owned_kb`）校验资源是否属于当前租户，防止越权操作平台或其他租户资源。
- 列表查询接口统一使用 `QueryParams` 依赖注入处理分页、筛选和排序，并通过 `paginated` 工具函数返回符合 JSON:API 风格的响应结构。
