- **核心沙箱层**：以 `PluginContext` (`context.py`) 为唯一入口，通过 `_require` 机制实施基于能力（Capabilities）的访问控制；底层依赖 `PluginDbProxy` (`context_primitives.py`) 拦截 SQL 执行并强制校验表名前缀（`px_{name}_*`），以及 `_NamespacedStorageProxy` 限制文件存储路径。
- **通信与分发层**：`PluginEventBus` (`event_bus.py`) 实现插件间异步解耦通知，具备超时保护与死信队列；`api_dispatcher.py` 和 `webhook_dispatcher.py` 分别作为管理/企业端 API 及外部 Webhook 的统一网关，负责路由匹配、权限门控及 Handler 动态加载。
- **宿主交互门面**：`HostReadFacade` (`host_read_facade.py`) 提供只读的宿主系统数据快照（如租户套餐、存储配置），防止插件直接操作核心数据库。
- **工具支撑层**：包含 `sse.py` (SSE 流式响应封装)、`asset_resolver.py` (静态资源安全解析) 及 `exceptions.py` (专用异常体系)，共同构成完整的运行时支持环境。
