- **市场客户端层**：`MarketplaceClient` (`marketplace.py`) 作为核心入口，负责从 GitHub Raw 内容或本地 `registry.json` 回退获取插件元数据，并通过 Redis 实现多级缓存策略。
- **安全传输层**：集成 `github_source_policy` 强制校验所有下载链接必须为 HTTPS 且限定在 GitHub 白名单域名内，防止供应链攻击。
- **安装预览引擎**：`preview.py` 提供 `generate_preview` 函数，在沙箱环境中解析 `plugin.yaml`，通过 `ExtensionRegistry` 检测扩展点冲突，并评估 Python 及插件间依赖状态。
- **更新监控模块**：`update_checker.py` 提供基于内存缓存的每日更新检查逻辑，对比已安装版本与市场最新版本。
- **包安全校验**：`package_security.py` 提供 ZIP 包的深度安全扫描，包括路径遍历防护、符号链接禁止、压缩比校验及单文件大小限制。
