- API 集成测试类统一继承 `tests.api.base.BaseAPITest`，并在 `setup` 方法中完成登录鉴权与 Token 设置。
- 服务层单元测试广泛使用 `unittest.mock.AsyncMock` 模拟数据库会话（`mock_db`）和 Redis 客户端，以隔离外部依赖。
- 回归测试文件命名遵循 `test_bug_{YYYY_MM_DD}_{identifier}.py` 格式，并在文档字符串中明确标注关联的 Bug ID 与测试范围。
- AI 引擎测试倾向于通过 `monkeypatch` 注入运行时依赖或替换底层网关调用，以验证编排逻辑而非真实的 LLM 响应。
