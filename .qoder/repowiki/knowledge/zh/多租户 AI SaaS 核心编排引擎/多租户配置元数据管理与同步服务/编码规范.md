- 采用声明式配置定义，每个配置分组对应一个独立的 Python 文件，在文件末尾通过赋值 `GROUP.configs = [...]` 完成注册。
- 所有配置元数据字段（如名称、描述）均使用 i18n key（`name_key`, `description_key`）而非硬编码字符串，以实现多语言支持。
- 配置值在数据库中统一序列化为 JSON 字符串存储，读取时由 `ConfigService` 根据 `value_type` 自动反序列化并执行类型校验。
- 采用双键名索引机制，`ConfigRegistry` 同时维护 `group_code -> config_key` 和跨分组的 `config_key` 查找索引，以支持灵活的查询需求。
