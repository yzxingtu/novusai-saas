- 采用模块化目录结构，每个子模块（dept, menu, role）包含列表页（list.vue）、数据配置（data.ts）和表单弹窗/抽屉（modules/form.vue）。
- 基于 Vben Admin 框架，使用 `useVbenVxeGrid` 封装表格逻辑，`useVbenModal` 或 `useVbenDrawer` 处理表单交互。
- 数据层通过 `#/api/system/*` 接口与后端通信，UI 层依赖 Ant Design Vue 组件库。
- 列表页与表单组件通过 `connectedComponent` 建立连接，实现状态共享与事件回调（如 success 刷新表格）。
