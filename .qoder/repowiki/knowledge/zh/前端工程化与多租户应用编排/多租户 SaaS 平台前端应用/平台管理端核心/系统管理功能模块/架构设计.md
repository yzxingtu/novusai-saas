- **模块化视图结构**：每个子功能（如 `organization`, `codegen`, `task-logs`）独立为子目录，包含入口组件（`index.vue` 或 `list.vue`）及配套的逻辑文件（`data.ts`, `composables/`, `modules/`）。
- **逻辑与表现分离**：普遍采用 `data.ts` 定义表格列（`useColumns`）和搜索表单（`useGridFormSchema`），在 Vue 组件中通过 `useCrudPage` 适配器统一驱动数据加载与交互。
- **组合式 API 封装**：复杂交互逻辑（如代码生成的作用域同步 `use-codegen-builder-scope.ts`）被抽取为 Composables，实现状态管理与 UI 渲染的解耦。
- **业务组件复用**：深度依赖 `#/components/business` 下的通用业务组件（如 `OrgTree`, `MemberPanel`, `IdentityDisplay`），确保跨模块交互体验的一致性。
