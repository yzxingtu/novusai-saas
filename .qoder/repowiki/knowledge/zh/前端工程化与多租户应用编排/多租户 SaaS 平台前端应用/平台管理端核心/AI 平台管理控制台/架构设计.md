- **分层架构**：采用 `views` (UI) -> `composables` (业务逻辑/状态) -> `api` (数据接口) 的分层设计，通过 `useCrudPage` 或自定义 composables（如 `useAgentListPage`）解耦视图与逻辑。
- **模块化组织**：按资源域划分为 `agents`、`models`、`providers`、`skill-packages` 等子模块，每个子模块包含独立的列表页、详情页及表单组件。
- **共享 UI 模式**：通过 `_shared` 目录下的 `AIPageHeroCard` 等组件统一页面头部风格，利用 `modules` 子目录封装复杂页面的局部功能（如 Agent 的 RAG 配置 Tab）。
- **API 聚合**：在 `api/admin` 下集中定义各资源的 RESTful 接口（如 `ai-agents.ts`），并导出 TypeScript 类型定义以保障前后端契约一致性。
