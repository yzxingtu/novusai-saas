- **入口与导出**：`src/index.ts` 作为统一出口，聚合本地定义的 hooks 并透传 `@vben-core/composables` 的能力。
- **依赖方向**：依赖 `@vben/stores`（Pinia 状态）、`@vben/preferences`（偏好设置）及 `@vben/utils`（工具函数），实现业务逻辑与底层状态的解耦。
- **功能分层**：
  - **UI 交互层**：`use-hover-toggle`、`use-content-maximize` 处理复杂的 DOM 事件与状态切换。
  - **主题适配层**：`use-design-tokens` 针对 Ant Design Vue、Naive UI、Element Plus 提供动态 CSS 变量映射。
  - **业务逻辑层**：`use-tabs` 封装路由与标签页联动，`use-app-config` 处理环境变量注入。
- **技术实现**：广泛使用 Vue 3 Composition API (`ref`, `computed`, `watch`) 及 `vue-router` 钩子。
