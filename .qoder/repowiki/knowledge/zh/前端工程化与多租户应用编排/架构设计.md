- **Monorepo 编排**：采用 pnpm workspace 管理 `apps`（业务应用）、`packages`（基础库）、`internal`（工程配置）及 `scripts`（运维脚本），实现依赖提升与局部链接。
- **任务调度**：利用 Turbo 定义 `build`、`dev` 等任务的拓扑依赖，确保底层工具库变更时自动触发上层应用的增量构建与缓存命中。
- **标准化基建**：通过 `internal` 目录下的共享配置包（如 `eslint-config`、`vite-config`、`tsconfig`）强制统一各子模块的代码规范、编译选项与构建行为。
- **应用隔离与共享**：`apps/web-antd` 与 `playground` 作为独立应用入口，通过引用 `@core` 和 `effects` 等共享包复用 UI 组件、状态管理及 API 逻辑，同时保持业务域的路由与布局隔离。
