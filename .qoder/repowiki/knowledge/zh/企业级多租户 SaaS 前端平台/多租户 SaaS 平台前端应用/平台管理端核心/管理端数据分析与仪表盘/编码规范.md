- 所有 ECharts 图表组件均采用 `ref` + `useEcharts` Hook 模式，并通过 `watch` 监听 `props.data` 变化触发 `renderEcharts` 重绘。
- 图表组件在数据为空时统一降级渲染 `ant-design-vue` 的 `Empty` 组件或自定义占位符，确保界面健壮性。
- Dashboard 页面通过 Composable (`useAdminDashboard`) 集中处理数据获取与状态转换，视图层仅负责声明式渲染。
- API 请求参数与响应数据均定义了对应的 TypeScript Interface，并统一使用 `requestClient` 进行 HTTP 调用。
