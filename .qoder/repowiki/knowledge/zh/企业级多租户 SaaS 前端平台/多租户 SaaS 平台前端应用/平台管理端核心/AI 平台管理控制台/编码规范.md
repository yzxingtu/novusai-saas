- 列表页普遍采用 Composable 模式（如 `useXxxPage`）封装分页、搜索、筛选及 CRUD 操作逻辑，实现视图与状态管理的分离。
- 复杂表单与详情查看通常拆分为独立的 `modules/form.vue` 或 `detail` 子组件，并通过 Drawer 或 Modal 形式按需加载。
- 页面头部统一使用 `AIPageHeroCard` 或 `AIGatewayQuickStartHero` 组件展示关键指标（Metrics）与上下文标签（Chips），保持视觉一致性。
- API 层遵循资源导向命名规范，每个资源对应一个独立的 TS 文件，内部包含完整的请求函数及对应的 Interface 类型定义。
