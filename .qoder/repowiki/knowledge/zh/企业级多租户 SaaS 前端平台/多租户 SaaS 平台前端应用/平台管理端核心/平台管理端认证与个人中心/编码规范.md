- API 响应字段统一从后端的 snake_case 转换为前端的 camelCase（如 `access_token` 转为 `accessToken`），并在 API 层完成映射。
- 认证相关的敏感操作（如登录、刷新 Token）均通过 `useMultiAuthStore` 统一调度，确保不同端点（Admin/Tenant）的 Token 互不干扰。
- 视图组件中的异步操作（如保存资料、上传头像）均采用 try-catch-finally 模式管理 loading 状态与错误提示。
- 菜单与权限数据在获取后通过 `transformMenuData` 进行标准化处理，自动补全路由路径前缀并提取权限码。
