- **视图层**：采用卡片式网格布局（`index.vue`, `marketplace/index.vue`），集成统计摘要、多维筛选（状态/类型/分类）及分页功能。
- **交互逻辑层**：通过 `usePluginAdminActions.ts` 封装启用、禁用、卸载、修复等核心业务动作，统一处理进度反馈与异常恢复；`PluginInstallWizard.vue` 实现“上传/预览-确认”的两步安装流程。
- **数据访问层**：依赖 `plugin.ts` 和 `plugin-marketplace.ts` 定义 RESTful API 接口，涵盖插件 CRUD、依赖管理、许可证激活及市场元数据获取。
- **辅助模块**：包含 `plugin-recovery.ts` 用于诊断运行时健康状态，`data.ts` 提供类型推导与 UI 映射常量。
