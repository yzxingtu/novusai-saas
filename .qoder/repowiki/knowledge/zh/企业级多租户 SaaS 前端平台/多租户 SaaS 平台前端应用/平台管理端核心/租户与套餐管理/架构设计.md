- **视图层**：采用 `useCrudPage` 声明式 CRUD 模式，通过 `list/index.vue`（租户列表）和 `plans/index.vue`（套餐列表）实现数据展示与交互。
- **接口层**：在 `api/admin/` 下定义独立模块（`tenant.ts`, `plan.ts`, `tenant-domain.ts`），负责 RESTful 请求封装及后端 snake_case 到前端 camelCase 的数据转换。
- **组件化设计**：复杂业务逻辑（如域名 DNS 引导、SSL 证书管理、管理员重置密码）被拆分为 `modules/` 下的独立 Vue 组件，通过 Drawer/Modal 形式按需加载。
- **依赖方向**：视图层依赖 API 模块获取数据，并通过 `#/adapter/vxe-table` 适配器处理表格渲染与状态同步。
