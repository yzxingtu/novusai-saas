- **路由层**：通过 `router/routes/tenant/index.ts` 定义静态路由，区分认证态（`AuthPageLayout`）与主应用态（`BasicLayout`），并维护核心免检路由白名单。
- **视图层**：采用组合式 API 架构，Dashboard 使用 `useTenantDashboard` Composable 封装复杂的数据聚合与实时信号处理逻辑；Analytics 页面集成日期筛选与多维度 ECharts 图表组件。
- **接口层**：在 `api/tenant/` 目录下按业务域（auth, dashboard, analytics, permission）组织 API 函数，统一处理后端 snake_case 到前端 camelCase 的数据格式转换。
- **依赖方向**：视图组件依赖 Store（如 `useUserStore`, `useSocketIOStore`）进行状态同步，并通过 API 层与后端 `/tenant/*` 接口交互。
