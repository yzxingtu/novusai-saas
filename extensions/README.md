# Reusable Extensions

This directory is for reusable packages that are not tied to one customer
project and are not core Yudi SaaS code.

Use it for:

- reusable plugins
- connectors
- report templates
- import/export packages
- skill packages
- integration assets shared by multiple customer projects

If an extension becomes core platform behavior, move the capability upstream
through the normal Yudi design and review flow.

Start new reusable packages from `extensions/_template/`.
