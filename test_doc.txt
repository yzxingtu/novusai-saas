NovusAI 平台介绍

NovusAI 是一个多租户 SaaS 平台，提供 AI 驱动的智能服务。

核心功能：
1. 智能体管理：支持创建和管理多个 AI 智能体，每个智能体可以绑定不同的技能包和知识库。
2. 知识库系统：支持文档上传、自动分块、向量化存储，实现 RAG 检索增强生成。
3. 多模型网关：统一管理多个 AI 供应商（DeepSeek、阿里百炼等），支持模型切换、故障转移和负载均衡。
4. 技能包系统：可扩展的工具调用框架，支持自定义技能开发和第三方插件集成。
5. 多租户隔离：每个租户独立的数据空间、配额管理和权限控制。

技术栈：
- 前端：Vue 3 + Vben Admin + Ant Design Vue
- 后端：FastAPI + SQLAlchemy + PostgreSQL
- 向量数据库：支持多种向量存储后端
- AI 网关：支持 OpenAI 兼容协议的统一接口

平台优势：
- 企业级安全：RBAC 权限控制、API Key 管理、操作审计日志
- 弹性扩展：支持水平扩展和多租户资源隔离
- 开发友好：提供 CRUD 代码生成器、插件化架构、完善的 API 文档
