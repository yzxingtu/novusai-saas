# Weather Realtime Skill

This skill provides live weather lookup backed by the Weather Widget plugin.

Use it for:
- current weather in a city
- multi-day forecast
- temperature, humidity, wind speed, UV index, and condition checks

Do not use it for:
- historical climate analysis
- severe weather alerts that require official emergency feeds
- non-weather travel planning questions unless live weather is explicitly needed
