# Security policy

## Supported versions

We prioritize security fixes for the **default / main development branch** (often `main` or `develop`, as labeled in this repository). Older release branches may receive backports at maintainers’ discretion.

## Reporting a vulnerability

**Please do not** file a public GitHub issue for undisclosed security vulnerabilities.

Instead:

1. **If this repository is on GitHub:** use **[Private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** for the repository, if enabled by maintainers; or
2. Contact the maintainers through a **private channel** agreed within your organization (email, internal tracker, etc.).

Include:

- A short description of the issue and its impact
- Steps to reproduce (proof-of-concept if safe)
- Affected versions or commits, if known
- Your suggestion for a fix (optional)

## Disclosure timeline

- We aim to acknowledge receipt within a **few business days**.
- We will work on a fix and coordinate disclosure with you; please allow time for patching and release before public discussion.

Thank you for helping keep NovusAI SaaS users safe.
